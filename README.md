# Integrating With HubSpot I: Foundations Practicum Hammad Ahmad

This project demonstrates a Node.js and Express application integrated
with the HubSpot CRM API.

## Custom Object

The application uses a custom HubSpot CRM object called `Books`.

The object contains the following properties:

- Name
- Author
- Genre

The custom object is associated with HubSpot Contacts.

## HubSpot Custom Object

[View Books in HubSpot](https://app-na2.hubspot.com/contacts/247266011/objects/2-267792298/views/all/list)

## Technologies

- Node.js
- Express
- Axios
- Pug
- HubSpot CRM API
